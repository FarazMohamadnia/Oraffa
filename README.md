# عرفا (Orrafa) — Redesign

بازطراحی حرفه‌ای وب‌سایت مؤسسه علمی آموزشی عرفا با:

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router (RTL)
- React Bits (انیمیشن‌ها و پس‌زمینه‌ها)
- Motion / GSAP

## اجرا

```bash
npm install
npm run dev
```

## بیلد

```bash
npm run build
npm run preview
```

## صفحات

- `/` خانه
- `/about` درباره ما
- `/courses` کاتالوگ دوره‌ها
- `/courses/:slug` جزئیات دوره
- `/instructors` مدرس‌ها
- `/blog` وبلاگ
- `/contact` تماس
- `/cart` و `/account` مسیرهای CTA به مشاوره

## اسکیل‌ها

- `.cursor/skills/ui-ux-pro-max`
- `.agents/skills/*` (Emil Kowalski animation / UI skills)
